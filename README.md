## 1.5.30：人数筛选跟随当前网址（2026-10-10）

“最小宗亲人数”不再全局保存或输入后立即应用。输入只改变草稿，点击官方“确定”后才生效；点击“重置”立即清空人数和官方条件，恢复树节点及布局。关闭弹窗保留本次草稿，不改变已经生效的筛选。

人数条件使用独立网址参数 `mofangMinSamples`，例如 `?mofangMinSamples=5`。刷新带参网址保留条件，打开普通网址从 0 开始，不影响其他标签页；前进、后退按各自网址恢复。树内沿用筛选的导航携带该参数。生效后筛选按钮旁显示“宗亲人数 ≥ N”，旁边的“清除”只撤销人数条件，保留官方姓氏、籍贯和民族条件。扩展参数不会混入官方 `filterParams` 或官方筛选接口，官方宗亲合计口径保持不变。

升级后自动忽略并尽力删除旧全局阈值，无需手动清理。若官方组件结构不能识别，该页人数筛选停用并显示提示，官方筛选仍可使用。更新方式仍是覆盖原安装目录中的扩展文件、重新加载扩展，再刷新23魔方网页。

本地组件回归使用 Vue 2.7.16 / Vue Router 3.6.5，仅作为开发测试依赖，不加入安装包。`node scripts/node-filter-preview.mjs` 可启动验证页。真实登录态验收尚未完成：当前 Edge 自动化连接认证不可用；本地浏览器与模拟官方组件验证不能替代该项验收。

- 输入区县名称，点击搜索结果可定位；也可按省、市名称查找其下区县，最多显示40条候选，输入更完整名称可缩小范围。
- 「恢复全国」恢复视野，不清除网站的籍贯筛选；清除筛选需使用网站原有筛选控件。
- 「全屏查看」适合密集地区；按 Esc 退出。
- 支系切换及籍贯筛选自动同步。网站姓氏、民族筛选只是对应列表的显示筛选，不会被误用为地域频率条件。

## 数据口径与边界

- 原始频率来自当前网页 `branchData.geographicDistribution.chartItems`，保留原始数值，不根据个人宗亲条目重新计算。
- 全国同一支系使用统一分位数色阶。籍贯筛选不改变该支系全国色阶。数值重复时合并重复分界；图例保留足够精度以区分分界。
- 色阶方向为绿色低频、红色高频；分位数分档方式保持不变。
- 百分比两位小数显示，与网站一致；明确的零显示 `0.00%`，极低值显示 `<0.01%`。灰色是未提供或未匹配，不表示零。
- 地图含2,890个默认区县／县市边界及298个可按城市选择的旧版区县边界。基础图来自23魔方，旧版图来自DataV，台湾县市补图来源、授权和下载摘要见 `assets/map-provenance.json`。没有区县数据时，不把省级、市级值填给区县。
- 按行政区代码、名称和省份核对；仅限定的跨编码地区另用显式对应规则。旧版接口未声明统一测绘年份，因此不将“旧版边界”称为精确的某年行政界线。代码冲突、无效值和无可靠边界的地区保留在未匹配明细。
- 网站人口比例来自其样本及统计处理；插件只展示网站公开汇总，不能把颜色解释成抽样精度或统计显著性。地图边界版本与频率的旧区划可能不同。
- 本地使用，不在扩展商店发布。不声明拥有底图权利；底图来源记录在 `assets/map-provenance.json`。

## 开发

需要 Node.js 22+。使用 npm 安装锁文件指定的依赖：

```text
npm ci
npm run check
npm test
npm run build
```

源码包自带地图及3个仅含公开地域汇总的测试快照，无需重新采集即可构建和测试。需要更新地图时运行 `npm run maps`，每批最多2个请求，缓存至 `.cache/maps`，失败重试3次并写入来源报告；存在失败则以非零状态退出，不声称完整采集。更新快照运行 `npm run fixtures`。

`npm run preview` 启动本地验证页面，在控制台给出的地址用普通浏览器检查地图。预览使用站点汇总快照和模拟页面组件，包含一个故意从零尺寸开始的真实 ECharts 省级地图，用于验证切换后的重绘；不等同于安装后在真实23魔方页面的测试。发布用的 `dist` 不含预览代码。

主要模块：`src/bridge.ts` 负责当前支系和路由同步；`src/model.ts` 负责数据复制、匹配和色阶；`src/content.ts` 负责地图和交互。`scripts/collect-maps.mjs` 统一简化相邻边界、保留所有区域形状。

古DNA模块在 `src/ancient/`：`model.ts` 规范化与范围判定，`parser.ts` 详情解析，`engine.ts` 可恢复查询与缓存，`background.ts` 浏览器通信与任务归属，`ui.ts` 节点按钮和侧栏，`source*.ts` 正常网页同步。使用 `npm run preview:ancient` 检查侧栏；该预览只使用AU334和AU104785两条公开详情回归样本及模拟传输，不能当作全量或实时查询。

TheYtree源站字段依据已核对的网页脚本：`/static/js/theytree.js?v=20260101-6`；公开树地址 `/api/ysnp/theytree/?haplogroup=...`，展开地址 `/api/ysnp/theytree/node/?hid=...`。样本详情地址严格使用源站返回的 `sid_encrypted`，遵循源站实际点击逻辑。`scripts/inspect-theytree.mjs` 只做字面量解包检查，未使用eval执行下载脚本。

源码内古DNA快照仅保留正式树关系及公开古人资料，现代样本仅保留排除计数；不会在运行时冒充实时结果。更新快照可运行 `scripts/ancient-fixtures.ts`，遇到访问限制停止，使用正常网页同步检查，不伪造请求身份。

## 故障排查

- 没出现地图：确认扩展已启用，刷新已打开的网页，并滚动到「籍贯地分布」。
- 提示「本页未提供可用的地域分布数据」：该节点可能没有支系分析数据；例如 O-BY11777。插件不会补造频率。
- 提示数据结构变化或无法读取：先刷新；若仍出现，需适配网站的新版本。失败时会保留原页面。
- 部分区县灰色：查看地图下方未匹配明细；网站未提供的区县不在频率记录中，不会被计为 0%。
- 浏览器受组织策略管理：开发者模式或加载解压缩扩展可能不可用，需要按组织的正常安装流程处理。

最低 Chromium 版本为111；实际交付环境的验证范围见 `VALIDATION.md`。
