## 1.1.5：上游查询同步下游缓存

- 上游「包含下游」完整查询结束后，自动为已核查节点生成「本节点」缓存，并刷新树上按钮，无需逐个点击。节点按钮显示其直接挂载的古样本数，不是整个下游总数；确认完整且没有直接样本时缓存0。
- 点击下游节点直接使用缓存；其「包含下游」也可从上游完整结果中截取并重建路径，无额外网络查询。不会给每个节点重复保存一整棵树。
- 正常TheYtree网页同步完成后同样更新；升级前已取得的完整上游缓存，再次打开「包含下游」即可补齐节点缓存，不重新抓取，采集时间不延长。
- 未完成、失败、待核对、暂定归类及无法确认挂载关系的结果不生成完整下游缓存。改名节点只复用此前已确认且仍有效的对应关系，未对应名称不推测关联。
- 已打开的页面在缓存更新后重新读取可见节点数量，保持原有千年门槛和未查询紧凑图标。

## 1.1.3：同名快速查询与千年门槛

- **同名优先**：例如两站均为 `O-F8`，直接读取该节点古DNA，不读取23魔方SNP、不逐项搜索SNP、不请求TheYtree等价列表。同名节点的树响应直接用于后续样本查询。仅确认没有同名节点时，自动进入原有双向SNP核对；访问失败不当作未匹配。
- **隐藏不足1000年的入口**：按23魔方页面显示的「形成时间距今」判断，父系树和支系分析页均不再添加这些节点的古DNA按钮。正好1000年仍显示；年龄未提供或无法明确解析时保留。页面动态更新年龄后也会移除旧按钮。
- 隐藏节点不再参与按钮定位或缓存数量查询；网页切到后台时暂停古DNA界面的轮询和布局扫描。父节点「包含下游」的结果范围不因此改变。
- 已核对改名节点仍可复用有效缓存，不需要反复登录核对。手动刷新会重新查询。同名快速路径的结果缓存与旧版隔离。

## 1.1.2：TheYtree登录态等价SNP核对

新增双向列表核对，解决23魔方改名后不再保留TheYtree主名称的情况。例：`O-MF190013 → O-FT130664`，TheYtree列表包含 `Y86790, TYT278842/MF190013`，共同SNP为 `MF190013、Y86790`。斜杠表示同一突变的多个名称，分组及原文保留。

**使用方法**：更新扩展并刷新23魔方后，点击节点「古DNA」。如果提示需要核对TheYtree列表，点击「打开TheYtree同步」。在打开的正常网页登录，点击顶部扩展横条「重新同步当前树」；已登录时会自动读取列表并继续查询，完成后回到23魔方。也可在该同步页面打开对应节点的 **+N SNPs** 弹窗，再点重新同步，作为可见弹窗读取的备用方式。请保持同步页面开启至完成。

## 古DNA查询使用方法

更新后扩展名称为「23魔方 · 地域地图与古DNA」。原有三级频率地图、红绿配色和原省级图修复均保留。

1. 在父系树的正式节点旁点击 **古DNA**；个人末端样本行不添加按钮。支系分析页标题下也有「古DNA查询 · TheYtree」入口。
2. 右侧面板默认查 **本节点**，切到 **包含下游** 可查看该支系下的古样本。可搜索AU编号、遗址、文化，按国家筛选。
3. 数据先尝试使用7天内的完整缓存；点击「刷新」会重新获取树和详情，不复用旧详情缓存。
4. 遇到403、登录要求或动态数据无法读取时，点 **打开TheYtree同步**。正常打开的源站页面顶部会出现同步横条，完成后回到23魔方查看；若树尚未加载或有折叠内容，可在源站正常展开后点「重新同步当前树」。浏览器不会自动绕过验证或登录。
5. 查询可以暂停、继续。后台休眠或浏览器重启后，保存的未完成任务会显示为可继续；源站网页同步暂停后，正在进行的请求可能完成，但其过期结果不会覆盖新查询。

只将源站明确标记为 Ancient／古人（网页实际树加载器中的 `stype=2`）的样本计入已确认古DNA。AU编号本身不代表古人；现代科研及个人样本字段会在入库前丢弃。未确认类别或带问号的暂定归类单列，不计入已确认数量。

本节点是TheYtree直接挂载关系，并不意味着已证明排除了所有下游。每条下游结果保留实际挂载节点和父子路径。不同网站同名标记的下游划分可能不同，面板以TheYtree为来源，不改写23魔方树，也不将古样本混入现代人口频率地图。

1.1.1按节点完整SNP查询，再用23魔方本节点SNP中出现的TheYtree主名称交叉核对。源站搜索返回默认全树不视为命中。若两站划分不一致，或TheYtree目标主SNP不在当前列表中，保留待核对，不声称两个节点完全等价。`src/ancient/aliases.ts` 仍保留人工核实别名接口；不做模糊匹配、不自动改用上游。未匹配、访问失败、未完成查询不显示为“0个古样本”。

年代保留原文。排序可选「cal BP」或「BP」，各自按区间中值由早到晚排序，其他口径和缺失值置后；“距今”、朝代及BP不会被混算。覆盖率、平均深度分别显示；名称中含有年代而详情年代字段为空时，不猜测填入。树与详情的年代不同时保留对照，挂载支系不一致时列为待核对。

数据保存在浏览器本地 `chrome.storage.local`，不上传23魔方个人资料。只在用户点击后查询该支系，不预抓取两站全树。后台请求单并发、至少间隔500毫秒；源站同步任务同样串行请求。只有查询范围和详情都完成且无待核对记录，才显示完整缓存数量。

## 安装（无需 Node.js）

1. 将安装包解压到一个固定位置。不要只在 ZIP 压缩包中打开文件。
2. Edge 地址栏输入 `edge://extensions`；Chrome 输入 `chrome://extensions`。
3. 开启「开发人员模式 / 开发者模式」，点击「加载解压缩的扩展 / 加载已解压的扩展程序」。
4. 选择安装包里的 **extension** 文件夹；该文件夹内能直接看到 `manifest.json`。如果使用源码目录，选择 **dist** 文件夹。
5. 打开或刷新 https://www.23mofang.com/ancestry/ytree/O-CTS7316/branch ，滚动到「籍贯地分布」。

请保留所选文件夹；删除、移动文件夹后扩展会失效。更新时用新版覆盖同一文件夹，在扩展管理页点击「重新加载」，再刷新23魔方页面。卸载时在扩展管理页点击「删除」即可。

- 输入区县名称，点击搜索结果可定位；也可按省、市名称查找其下区县，最多显示40条候选，输入更完整名称可缩小范围。
- 「恢复全国」恢复视野，不清除网站的籍贯筛选；清除筛选需使用网站原有筛选控件。
- 「全屏查看」适合密集地区；按 Esc 退出。
- 支系切换及籍贯筛选自动同步。网站姓氏、民族筛选只是对应列表的显示筛选，不会被误用为地域频率条件。

## 数据口径与边界

- 原始频率来自当前网页 `branchData.geographicDistribution.chartItems`，保留原始数值，不根据个人宗亲条目重新计算。
- 全国同一支系使用统一分位数色阶。籍贯筛选不改变该支系全国色阶。数值重复时合并重复分界；图例保留足够精度以区分分界。
- 色阶方向为绿色低频、红色高频；分位数分档方式保持不变。
- 百分比两位小数显示，与网站一致；明确的零显示 `0.00%`，极低值显示 `<0.01%`。灰色是未提供或未匹配，不表示零。
- 地图含2,840个区县边界，采集自网站本身，随扩展离线打包；全国轮廓和只有较粗边界的地区作为灰色底图。没有区县数据时，不把省级、市级值填给区县。
- 按行政区代码和名称双重核对。旧代码、同代码不同名称、重复代码、无效值都会进入未匹配明细，不做未经核实的区划合并或更名映射。
- 网站人口比例来自其样本及统计处理；插件只展示网站公开汇总，不能把颜色解释成抽样精度或统计显著性。地图边界版本与频率的旧区划可能不同。
- 本地使用，不在扩展商店发布。不声明拥有底图权利；底图来源记录在 `assets/map-provenance.json`。

## 开发

需要 Node.js 22+。使用 npm 安装锁文件指定的依赖：

```text
npm ci
npm run check
npm test
npm run build
```

源码包自带地图及3个仅含公开地域汇总的测试快照，无需重新采集即可构建和测试。需要更新地图时运行 `npm run maps`，每批最多2个请求，缓存至 `.cache/maps`，失败重试3次并写入来源报告；存在失败则以非零状态退出，不声称完整采集。更新快照运行 `npm run fixtures`。

`npm run preview` 启动本地验证页面，在控制台给出的地址用普通浏览器检查地图。预览使用站点汇总快照和模拟页面组件，包含一个故意从零尺寸开始的真实 ECharts 省级地图，用于验证切换后的重绘；不等同于安装后在真实23魔方页面的测试。发布用的 `dist` 不含预览代码。

主要模块：`src/bridge.ts` 负责当前支系和路由同步；`src/model.ts` 负责数据复制、匹配和色阶；`src/content.ts` 负责地图和交互。`scripts/collect-maps.mjs` 统一简化相邻边界、保留所有区域形状。

古DNA模块在 `src/ancient/`：`model.ts` 规范化与范围判定，`parser.ts` 详情解析，`engine.ts` 可恢复查询与缓存，`background.ts` 浏览器通信与任务归属，`ui.ts` 节点按钮和侧栏，`source*.ts` 正常网页同步。使用 `npm run preview:ancient` 检查侧栏；该预览只使用AU334和AU104785两条公开详情回归样本及模拟传输，不能当作全量或实时查询。

TheYtree源站字段依据已核对的网页脚本：`/static/js/theytree.js?v=20260101-6`；公开树地址 `/api/ysnp/theytree/?haplogroup=...`，展开地址 `/api/ysnp/theytree/node/?hid=...`。样本详情地址严格使用源站返回的 `sid_encrypted`，遵循源站实际点击逻辑。`scripts/inspect-theytree.mjs` 只做字面量解包检查，未使用eval执行下载脚本。

源码内古DNA快照仅保留正式树关系及公开古人资料，现代样本仅保留排除计数；不会在运行时冒充实时结果。更新快照可运行 `scripts/ancient-fixtures.ts`，遇到访问限制停止，使用正常网页同步检查，不伪造请求身份。

## 故障排查

- 没出现地图：确认扩展已启用，刷新已打开的网页，并滚动到「籍贯地分布」。
- 提示「本页未提供可用的地域分布数据」：该节点可能没有支系分析数据；例如 O-BY11777。插件不会补造频率。
- 提示数据结构变化或无法读取：先刷新；若仍出现，需适配网站的新版本。失败时会保留原页面。
- 部分区县灰色：查看地图下方未匹配明细；网站未提供的区县不在频率记录中，不会被计为 0%。
- 浏览器受组织策略管理：开发者模式或加载解压缩扩展可能不可用，需要按组织的正常安装流程处理。

最低 Chromium 版本为111；实际交付环境的验证范围见 `VALIDATION.md`。
