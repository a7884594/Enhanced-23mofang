# 23魔方 · 全国区县频率地图

独立 Edge / Chrome 扩展。打开23魔方父系节点的「支系分析」页面，自动显示全国区县频率地图，无需逐省展开。

## 1.0.3 更新

- 新增中间层级：**全国区县 → 全国市级 → 原省级图**。默认仍显示全国区县。
- 市级模式只显示城市边界和网站提供的市级频率；支持城市搜索、缩放、全屏与籍贯筛选。色阶仍为绿色低频、红色高频，按全国当前层级数据计算。
- 直辖市使用网站已有的全市比例及全市边界，不合并“市辖区 / 县”子组。省直辖县级汇总等无独立市级边界的记录列入未匹配，不将县级值绘制到市图。
- 如果网站筛选精确到了某个县，市级图显示其所属市的原始全市比例，不重新计算为该县的值。
- 已打包367个市级边界。市级地图独立加载，不出现区县分割线，不从区县数据平均或加权推算市级频率。

## 1.0.1 更新

## 安装（无需 Node.js）

1. 将安装包解压到一个固定位置。不要只在 ZIP 压缩包中打开文件。
2. Edge 地址栏输入 `edge://extensions`；Chrome 输入 `chrome://extensions`。
3. 开启「开发人员模式 / 开发者模式」，点击「加载解压缩的扩展 / 加载已解压的扩展程序」。
4. 选择安装包里的 **extension** 文件夹；该文件夹内能直接看到 `manifest.json`。如果使用源码目录，选择 **dist** 文件夹。
5. 打开或刷新 https://www.23mofang.com/ancestry/ytree/O-CTS7316/branch ，滚动到「籍贯地分布」。

请保留所选文件夹；删除、移动文件夹后扩展会失效。更新时用新版覆盖同一文件夹，在扩展管理页点击「重新加载」，再刷新23魔方页面。卸载时在扩展管理页点击「删除」即可。

## 使用

- 默认显示「全国区县」；点「原省级图」可恢复网站原图，原始省市列表继续保留。
- 滚轮缩放、拖动地图；鼠标悬停显示省市县名称和频率，单击将结果固定到地图上方。
- 输入区县名称，点击搜索结果可定位；也可按省、市名称查找其下区县，最多显示40条候选，输入更完整名称可缩小范围。
- 「恢复全国」恢复视野，不清除网站的籍贯筛选；清除筛选需使用网站原有筛选控件。
- 「全屏查看」适合密集地区；按 Esc 退出。
- 支系切换及籍贯筛选自动同步。网站姓氏、民族筛选只是对应列表的显示筛选，不会被误用为地域频率条件。

## 数据口径与边界

- 原始频率来自当前网页 `branchData.geographicDistribution.chartItems`，保留原始数值，不根据个人宗亲条目重新计算。
- 全国同一支系使用统一分位数色阶。籍贯筛选不改变该支系全国色阶。数值重复时合并重复分界；图例保留足够精度以区分分界。
- 色阶方向为绿色低频、红色高频；分位数分档方式保持不变。
- 百分比两位小数显示，与网站一致；明确的零显示 `0.00%`，极低值显示 `<0.01%`。灰色是未提供或未匹配，不表示零。
- 地图含2,840个区县边界，采集自网站本身，随扩展离线打包；全国轮廓和只有较粗边界的地区作为灰色底图。没有区县数据时，不把省级、市级值填给区县。
- 按行政区代码和名称双重核对。旧代码、同代码不同名称、重复代码、无效值都会进入未匹配明细，不做未经核实的区划合并或更名映射。
- 网站人口比例来自其样本及统计处理；插件只展示网站公开汇总，不能把颜色解释成抽样精度或统计显著性。地图边界版本与频率的旧区划可能不同。
- 本地使用，不在扩展商店发布。不声明拥有底图权利；底图来源记录在 `assets/map-provenance.json`。

## 权限

仅匹配 `https://www.23mofang.com/*`。之所以覆盖这个域名的所有页面，是为支持网站不刷新页面的站内跳转；只有 `/ancestry/ytree/{标记}/branch` 路径读取地域汇总并显示功能。其他路径不读取汇总、不显示地图。

不申请 cookies、history、tabs、downloads、storage、debugger 等权限，不访问其他域名，不上传数据。MAIN 脚本只发送经过字段白名单复制的地区汇总；不发送 Nuxt 完整状态、账号信息或个人宗亲资料。地图及 ECharts 都在安装包中，不从 CDN 执行代码。

## 开发

需要 Node.js 22+。使用 npm 安装锁文件指定的依赖：

```text
npm ci
npm run check
npm test
npm run build
```

源码包自带地图及3个仅含公开地域汇总的测试快照，无需重新采集即可构建和测试。需要更新地图时运行 `npm run maps`，每批最多2个请求，缓存至 `.cache/maps`，失败重试3次并写入来源报告；存在失败则以非零状态退出，不声称完整采集。更新快照运行 `npm run fixtures`。

`npm run preview` 启动本地验证页面，在控制台给出的地址用普通浏览器检查地图。预览使用站点汇总快照和模拟页面组件，包含一个故意从零尺寸开始的真实 ECharts 省级地图，用于验证切换后的重绘；不等同于安装后在真实23魔方页面的测试。发布用的 `dist` 不含预览代码。

主要模块：`src/bridge.ts` 负责当前支系和路由同步；`src/model.ts` 负责数据复制、匹配和色阶；`src/content.ts` 负责地图和交互。`scripts/collect-maps.mjs` 统一简化相邻边界、保留所有区域形状。

## 故障排查

- 没出现地图：确认扩展已启用，刷新已打开的网页，并滚动到「籍贯地分布」。
- 提示「本页未提供可用的地域分布数据」：该节点可能没有支系分析数据；例如 O-BY11777。插件不会补造频率。
- 提示数据结构变化或无法读取：先刷新；若仍出现，需适配网站的新版本。失败时会保留原页面。
- 部分区县灰色：查看地图下方未匹配明细；网站未提供的区县不在频率记录中，不会被计为 0%。
- 浏览器受组织策略管理：开发者模式或加载解压缩扩展可能不可用，需要按组织的正常安装流程处理。

最低 Chromium 版本为111；实际交付环境的验证范围见 `VALIDATION.md`。
