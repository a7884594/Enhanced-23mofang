## 故障排查

- 没出现地图：确认扩展已启用，刷新已打开的网页，并滚动到「籍贯地分布」。
- 提示「本页未提供可用的地域分布数据」：该节点可能没有支系分析数据；例如 O-BY11777。插件不会补造频率。
- 提示数据结构变化或无法读取：先刷新；若仍出现，需适配网站的新版本。失败时会保留原页面。
- 部分区县灰色：查看地图下方未匹配明细；网站未提供的区县不在频率记录中，不会被计为 0%。
- 浏览器受组织策略管理：开发者模式或加载解压缩扩展可能不可用，需要按组织的正常安装流程处理。

最低 Chromium 版本为111；实际交付环境的验证范围见 `VALIDATION.md`。
